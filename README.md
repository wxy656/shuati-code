# 刷题

个人使用的 iPad 网页刷题应用，题目、音频与学习记录保存在浏览器侧。

## 本地运行

```bash
npm ci
npm run dev
```

仓库自带 50 道样例题和音频，可直接运行。正式完整题库仍保存在本地 `public/banks/shanghai-poetry/`，不纳入 Git，也不会进入生产构建；重新生成样例时运行 `node scripts/prepare-sample.mjs`。

生产构建与预览：`npm run build`、`npm run preview`。完整的导入、离线与播放流程可先在电脑浏览器打开本地预览地址使用。iPad 在同一局域网通过电脑地址访问普通 HTTP 页面时可以在线刷题，但离线缓存需要 iPad 信任的 HTTPS 地址。电脑的 `localhost` 只代表电脑自身，不能作为 iPad 的访问地址。

管理页可从上次题目继续，或展开“跳到指定题号”定位；错题可在独立管理页勾选移出。学习记录可导出 JSON 并合并导入，默认保留本机设置和进度。正式题库可用 `node scripts/package-bank.mjs` 在本机生成 `releases/shanghai-poetry-v1.zip`，再于管理页选择 ZIP 导入；ZIP 包含 1499 题和 2998 段音频，未随网页发布。安装后缓存由浏览器管理，建议定期导出学习备份。

## 使用

打开站点后选择题库，点击“从第一题开始”或“继续练习”；需要定位时展开“跳到指定题号”。回答后可查看判题结果与解析；学习记录自动保存到当前浏览器。要离线使用，在联网时返回题库管理页，点击“准备离线资源”，等待题目和音频都显示准备完成。准备失败时再次点击可补齐缺失资源。iPad 可用 Safari 的“添加到主屏幕”创建入口。

学习记录只在当前站点来源与浏览器中；清除网站数据或更换域名会影响记录。题库音频约 200 MB，首次完整离线准备需要足够的网络流量和设备空间。

## 家长布置与按键

将 iPad 放在孩子附近、屏幕背向孩子，电视作为主要阅读屏幕，小键盘放在孩子手边。首次蓝牙配对、联网和按键设置由家长在 iPad 上完成。无线 HDMI 只是代替长连接线，电视与 iPad 显示同一画面；练习时要保持 iPad 页面运行。设备到手后，请先在题目上试按并确认电视画面和声音。

默认按键：A–F 选项、Enter 提交、左右方向键切题、R 重读、上下方向键滚动当前题。多选再次按同一选项可取消。按键贴纸可标为“选 A”到“选 F”、“提交”、“上一题”、“下一题”、“重读”、“向上阅读”、“向下阅读”。如果设备发出的按键不同，在管理页“按键设置”中选择动作并按一次物理键保存映射。两个动作需要不同的按键码；网页无法区分发出相同键码的两个物理键。旋钮如有，只用于当前题阅读滚动。

## 发布

在仓库 Settings → Pages 将 Source 设为 GitHub Actions 后，推送到 `main` 会运行 `Publish GitHub Pages` 工作流；也可在 Actions 手动运行。访问地址为 `https://wxy656.github.io/shuati-code/`。

当前工作流只发布仓库中的 50 道样例题和音频，不发布本地正式完整题库。正式 ZIP 已在本地生成，GitHub Release 附件尚未发布；管理页的下载入口指向仓库 Releases 页面，发布后可从那里下载。

## 本地浏览器验证

2026-10-28 在 Chromium 本地预览中使用真实样例题和完整题库：按键选 B、提交第 0001 题判错（标准答案 A）、统计记为 1 错；导出备份、手动移出错题，再导入旧备份后错题没有复活。暂停、重开可续做。将 191 MiB 的完整 ZIP 导入后，缓存含题目 JSON 和 2998 段音频，同题记录在 1499 题统计中仍只计一次；断网重开可进入题目并播放本机音频，分段请求返回 206。长解析可在题内滚动。当前真实题库均为单选，多选沿用一期已实现的判题链，但本轮没有真实多选题可走。iPad 主屏幕入口、无线 HDMI 画面与电视实际出声仍需真机观察。
